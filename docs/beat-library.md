# 鼓点库

## 菜单与使用流程

- 全局菜单为“文件、编辑、查看、项目、工具、帮助”。
- “工具 → 鼓点库”在没有打开项目时也能使用；提供上传、试听、下载、重命名、删除、查找和清理未使用资源。
- “工具 → 选项”集中管理应用选项，目前包含原有的界面语言设置。
- “项目 → 项目属性 → 节拍轨”只选择内置或库中的鼓点并试听；“打开鼓点库”保留当前属性草稿。

## PR #1 的两个 P2

1. 打开属性时使用内置音色，之后切换至已保存的自定义鼓点，试听仍被禁用。
2. 保存 A 后选择 B，再切换内置音色并应用，之后选回 A，界面和资源引用为 A，试听却可能残留 B。

现在按选中的资源 ID 加载和缓存音频。选择变化会停止旧试听，过期的异步加载不会覆盖新选择；
只有当前资源完成加载才能试听和应用。项目试听、导出、撤销、重做和放弃修改都按同一资源引用取音频。
原 PR 的分析期间 autosave guard 保留。

## 保存、共享与清理

鼓点属于同一站点、同一浏览器中的独立素材库。项目只保存引用；另存为项目复用同一个资源。
删除项目不会删除库中的鼓点，即便它是最后一个引用者；用户可保留素材供未来使用，或显式删除、清理。

上传保留原文件和标准化后的 PCM；文件限 3 秒、10 MB，通过原文件 SHA-256 去重。
列表显示时长、实际音频数据占用和项目引用。这里的占用包括 PCM 和原文件，不包含 IndexedDB 索引等额外开销。

显示名称与原始文件名分开保存。上传时默认取去掉扩展名的文件名，同名资源自动编号为 `Kick (2)`、`Kick (3)`。
“重命名”或 F2 可修改名称，首尾空白会去掉，限 80 个字符；空白名称或与其他资源重名会被拒绝，名称比较不区分大小写。
名称分配和重命名均在资源表的写事务中检查，并由唯一索引保证跨标签页一致性。重复上传相同内容会复用已有资源及其名称。
项目按资源 ID 读取库中的最新名称，改名不修改项目引用、原始文件名、音频或去重信息。下载保留原文件名，查找支持名称和原文件名。

删除前同时检查：

- 已保存项目的引用，在同一个 IndexedDB 写事务中复查并删除。
- 当前工作区、属性草稿、保存中的快照和撤销／重做记录，以 Web Locks 共享锁保护，覆盖其他标签页。
- 删除取得排他锁后才执行；关闭页面后浏览器自动释放临时占用。没有 Web Locks 的浏览器禁用实际删除，避免漏检其他页面。

清理只处理确认框所列的资源 ID，执行时逐一复查引用；之后新上传的资源不会被纳入，刚被使用的资源会跳过。
切换并保存项目后，如果旧鼓点仍在撤销记录中，需要关闭对应编辑页才能清理。

## 旧数据与备份

数据库从版本 2 升级至 3，保留原资源 ID、PCM 和项目引用，并从项目引用补齐文件信息。
没有项目引用的旧资源也会出现在库中，可手动清理。旧版没有保留原文件的音频下载为 WAV；新上传的下载原文件。
版本 4 为已有库资源补齐名称和唯一名称索引，同名文件自动编号，保留资源 ID、原文件和音频数据。

项目 JSON 仍只包含资源引用，不携带音频。跨站点或浏览器迁移时需单独下载、上传并重新选择鼓点。
